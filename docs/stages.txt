Stage 1

A POC which has the following:
* A Kotlin multiplatform project with a server and a UI (the server serving the UI), with them sharing code for the API between them, and the UI using Kotlin DOM APIs (like FramnaFolk does) to produce code in a theme styled liked the Lunamux website. The view using Kotlin DOM APIs has a BackingViewModel on the Kotlin side which serves as its view model. The view has a button and a counter display.
* The backing view model stores the counter in memory which is incremented by call from the view when the button is pressed.
* A StateFlow is emitted with a single state for the entire view. The UI listens and updates the counter display.
* No persistence, no database.
* Everything packaged to a Docker container I can deploy on Railway.
* Destination: a subdomain "lunicle.lunamux.dev" on the Lunamux website. Secret for now, no links to it.
* An instructions HTML with step-by-step instructions how to configure the domain, how to configure Railway and deploy the Docker file there. 

Stage 2

* Add OAuth to sign in with Google and Github.

Stage 3
